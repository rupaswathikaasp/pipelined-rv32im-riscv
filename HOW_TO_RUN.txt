Pipelined vs non-pipelined RV32IM (uRISC-V) - Cadence flow, 90 nm slow corner, 7.2 ns
Run everything from this folder, in bash (type "bash" first if the prompt is csh).

 1. scripts/sim.sh nonpipelined ; scripts/sim.sh pipelined      -> 10/10 tests, PERF cycles 16150 / 8563
 2. scripts/syn.sh all 7.2                                      -> Genus, both designs
    scripts/syn.sh pipelined_lp 7.2                             -> same RTL as pipelined + clock gating, high effort
 3. scripts/pnr.sh <design> 7.2                                 -> Innovus layout (runs in background)
    designs: nonpipelined | pipelined | pipelined_lp
 4. scripts/fix_setup.sh <design> 7.2                           -> post-route setup/hold clean-up (final2_* reports)
 5. scripts/fix_hold.sh pipelined_lp 7.2                        -> hold ECO buffers (final3_* reports), only if hold < 0
 6. scripts/backup.sh                                           -> tar.gz of results, e-mail it out of the lab PC

Settings live in config.sh (LEF order translated+macro, site gsclib090site, power ring Metal8/Metal9).
Constraints: constraints/riscv.sdc (same for every design).
rtl/pipelined is the new 5-stage core; rtl/nonpipelined is the original uRISC-V core
(github.com/ultraembedded/core_uriscv, Apache 2.0).
